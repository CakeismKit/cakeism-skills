# 源气办公室分镜包

把**已经写好的分镜提示词**装成一个可以直接导入无限画布的包：每镜的首帧 / 尾帧 / 视频提示词原样进流程，不再经过剧本、导演、分镜这些文本步骤，从「关键帧生成」直接开跑。

产物是一个目录：

```
分镜包_<用途>/
├── 分镜包.json      # 镜头、提示词、角色、场景、参考图文件名
└── 参考图/          # 与 JSON 里写的文件名逐字符一致
```

用户在画布里的入口是：**剧本 → 成片页面 → 右上角「导入分镜包」**（选 JSON + 多选参考图 → 「导入并建项目」）。

## 一、先确认三件事

动手前必须问清（有默认值就按默认走，但要说明）：

1. **参考图带哪些**：① 只带人物与场景图（纯文字重拍）；② 额外带原片截图（按原片构图，最像原片）。默认 ①。
2. **时长**：每镜几秒。默认沿用源文档；接口硬下限是 **5 秒**，低于 5 会被夹到 5。
3. **跑多少镜**：全量还是先来一个「前 3 镜试跑包」验证画风与人物一致性。**默认先出试跑包**——全量 29 镜约等于 87 次付费生成（首帧 + 尾帧 + 视频），试跑只要 9 次。

## 二、分镜包 JSON 契约

字段名必须完全一致（多余字段会被忽略，缺失字段有默认值）：

```json
{
  "title": "开源中国 · 29 镜头（纯文字重拍）",
  "aspectRatio": "9:16",
  "styleHint": "写实职场短剧，真人实拍，9:16 竖屏。按提示词纯文字生成，只带固定角色参考图与场景参考图；不增删人物、不增加第三人、不自行拼写文字。",
  "characters": [{ "name": "人物 A", "image": "人物A.png", "description": "中年东亚男性新员工，短寸头，黑色矩形框眼镜，黑色夹克" }],
  "scenes": [{ "name": "开源中国办公室", "image": "办公室.png", "description": "白墙品牌标识、玻璃隔断、白色办公桌" }],
  "shots": [
    {
      "shotNumber": 1,
      "shotType": "中景",
      "angle": "平视",
      "cameraMovement": "固定跟移。",
      "durationSeconds": 5,
      "action": "戴眼镜的新员工站在品牌墙前，身体侧向镜头。",
      "dialogue": "无对白。",
      "characterIds": ["人物 A"],
      "sceneId": "开源中国办公室",
      "referenceImages": ["镜头01.jpg"],
      "firstFramePrompt": "……（完整提示词，原样进生图）",
      "lastFramePrompt": "……",
      "videoPrompt": "……"
    }
  ]
}
```

导入后的行为（写包时要心里有数）：

- `firstFramePrompt / lastFramePrompt / videoPrompt` **原文使用**，一致性回环也不会改写它们，只会按原文重出。
- `characterIds` 省略时默认全部角色都算本镜出场；`sceneId` 省略时取第一个场景。
- `referenceImages` 里的每个文件名会被挂成该镜的 `frame` 参考图（图注是「本镜原始截图」），**只有纯文字重拍时才留空**。
- 角色图与场景图对**每个**镜头都生效，随机位一起发出去。
- `input / director / characters / scenes / storyboard / references` 六步会被直接标记为已完成，所以**角色页签、场景页签看起来是空的属正常**，参考图要到「分镜」页签的镜头缩略图里看。
- `durationSeconds` 走画布同一个 `clampDuration`：四舍五入并夹到 **5–15 秒**。
- `aspectRatio` 决定画面比例；`styleHint` 会作为「硬性风格要求」进每条提示词。

## 三、五步流程

### 第 1 步：解析源文档

源文档常见是拉片工具导出的 HTML（每镜一张卡片，含时间码、景别、机位、运镜、动作、对白 + 三条提示词）。**逐条完整抽出，不要概括、不要重写、不要合并镜头**。

- 抽出后先把结构化结果落一份 JSON（如 `29镜头_结构化.json`）再做后续处理，便于反复校验。
- 大文件不要整份读进上下文：按镜头切片读，或用脚本解析后只回报「镜头数 / 每条提示词长度 / 缺失项」。

### 第 2 步：提示词改写（只在需要「去原片化」时做）

用户要求「不借原片画面、纯文字重拍」时，把提示词里指向原片的话术换成文字描述与场景参考图。**逐条精确替换，不做整段重写**（整段重写会把原作者的镜头设计弄丢）：

| 原文 | 改成 |
| --- | --- |
| 以提供的本镜原始截图作为构图、机位、人物外观与背景参考；再以固定角色参考图锁定脸和服装。 | 本镜按纯文字描述生成：…场景按场景参考图重建。 |
| 按该镜头参考图保留空间关系 | 按场景参考图重建空间关系 |
| 以原始截图为首要参考，准确保持该镜头的构图…背景几何关系； | 准确保持人物的脸部比例、服装细节与场景的空间关系，构图与机位按本镜文字描述重新设计； |
| 保留原参考画面中的 | 保持场景参考图里的 |
| 按原参考图保持 | 按场景参考图保持 |
| 仅生成这一条原片镜头 | 仅生成这一条镜头 |
| 严格沿用原始镜头的景别和拍摄角度。 | 严格按上面写明的景别和拍摄角度。 |
| 如原片有字幕/大标题，后期单独叠加。 | 如需要标题或字幕，后期单独叠加。 |
| 只使用当前原镜头要求出现的人物 | 只使用本镜描述里出现的人物 |
| ；原片景别是“…”，运镜标记为“”。 | 。（整句删掉） |

改写完必须**回归扫一遍残留词**：`原片`、`原始截图`、`原参考`、`参考画面` 在三类提示词里的命中数应为 **0**（`videoPrompt` 里保留的「无对白 / 音乐」等原表备注不算残留）。

### 第 3 步：参考图准备

- 角色图：单幅正面半身像最好；**不要用三视图 / 多面板拼图**，图像模型会照抄排版。
- 场景图：同理，**多格（九宫格）图容易被模仿成多格输出**，需要时裁成单格单幅再用。
- 文件名保持原样复制（可能含全角 `＝`、中文顿号、空格）。**JSON 里写的名字和磁盘上的名字必须逐字符一致**，对不上的只会少一张参考图、不会报错。

### 第 4 步：组装写盘

- 目录命名带上用途与范围，例如 `分镜包_29镜头_只带人物场景`、`分镜包_29镜头_只带人物场景_前3镜`。
- 参考图放 `参考图/` 子目录，JSON 就写在包根目录，文件名固定 `分镜包.json`。
- 试跑包只保留前 N 镜（`shots` 切片），`title` 里注明「前 N 镜试跑」，其余字段照搬。

### 第 5 步：校验（交付前必做）

写一个校验脚本一次性检查，把结果打印出来：

1. `shots` 数量与源文档一致；`shotNumber` 连续且不重复。
2. 每镜三条提示词**都非空**，且与源文档逐字一致（改写规则除外）。
3. `durationSeconds` 全部 ≥ 5；`aspectRatio` 与 `styleHint` 有值。
4. `characters[].image / scenes[].image / shots[].referenceImages` 列的每个文件都真实存在于 `参考图/`（含全角字符）。
5. JSON 能被 `JSON.parse` 解析（写完用脚本重新读一遍）。
6. 单条提示词长度（加上系统提示词）不超过 **5000 字符**，超了要在交付时点出来。

## 四、交付时怎么跟用户说

一段话讲清四件事：

1. 包在哪（绝对路径）、多少镜、每镜几条提示词、带哪些参考图。
2. 导入路径：`http://localhost:5173` → **剧本 → 成片** → 右上角「**导入分镜包**」→ 选 `分镜包.json` + 多选 `参考图/` 里的图 → 「导入并建项目」→ 点「开始生成」（会从关键帧生成接着跑）。
3. 地址必须是 `localhost:5173`，不要用 `127.0.0.1:5173`（浏览器按来源隔离，换来源会看到空库）。
4. 这次要花多少钱/多少时间（每镜 = 首帧 + 尾帧 + 视频 三次生成，另有每镜一次一致性检查）。

## 五、常见坑

- **一张图里出现三份 / 多格**：一次请求带了多张参考图（角色 A + 角色 B + 场景）或参考图本身是多格图时最容易出现。修法是按镜精简参考图（`characterIds` 只写本镜出场的人）＋ 换单幅参考图＋在提示词最前面加「输出必须是一张单幅画面，禁止分格 / 分屏 / 拼贴 / 同一人物重复出现，不要把参考图并排画进同一张图」。
- **视频接口报时长非法**：`durationSeconds` 写 1–4 会被拒或夹到 5，源文档是短视频节奏时要在交付说明里讲明白。
- **豆包桥接「没有返回视频」**：提示词过长（1000+ 字符）或一次并发太多时容易复现；可以先把视频提示词压短或把并发降到 1–2 条再试。
- **别把原片帧混进「纯文字重拍」包**：`referenceImages` 留空才叫纯文字，带上就变成按原片构图了。
- **不要顺手改无关字段**：包里除了提示词与参考图清单，其余字段（景别 / 运镜 / 对白 / 时长）都照抄源文档。
