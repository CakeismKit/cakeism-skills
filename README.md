# cakeism-skills

Agent 技能集合，按 Skillhub 的入库约定组织，供只读技能目录「注册仓库 → 同步拉取」。

## 目录约定

```
skills/<分类>/<技能名>/SKILL.md
```

## 已收录

| 分类 | 技能 | 用途 |
| --- | --- | --- |
| productivity | `yuanqi-office-storyboard-pack` | 源气办公室分镜包：把拉片导出的分镜提示词文档（每镜首帧 / 尾帧 / 视频三条提示词）整理成可一键导入无限画布「剧本 → 成片」的分镜包（分镜包.json + 参考图目录），含提示词改写、参考图准备与逐项校验清单 |

## 怎么被收录

技能目录按「注册仓库 + 同步拉取」入库：拉取的就是本仓库里的 `skills/<分类>/<技能名>/SKILL.md`，
同步完成后该技能会以 `source=github` 出现在目录接口 `GET /api/skills` 的返回里。

## 使用回流

每用过一次技能，把使用结果与优化建议推回中台的 notes 接口（技能名 + 1~5 评分 + 结果与建议 + 标签），
供技能持续迭代。
